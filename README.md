# ConnectX Chat

A real-time LAN-based chat application developed using Java Socket Programming and UDP Multicasting.

## Features
- Multi-user real-time chat
- Username authentication
- Timestamp messaging
- Dark theme UI
- Online users display
- Custom app icon
- LAN communication using UDP Multicast

## Technologies Used
- Java
- Java Swing
- Socket Programming
- UDP Multicasting
- Multithreading
